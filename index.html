Privacy Policy for Plannernet Engagements Notifier

Last updated: March 2025

Information Collection and Use

This extension collects the following information:

  • Job listings data from Plannernet website
  • User-provided Telegram bot token and chat ID for notifications

Data Storage

All user settings are stored locally in your browser using Chrome's storage API. No data is stored on our servers.

External Services

This extension integrates with:

  • Telegram's API for sending notifications (when configured by the user)
  • Plannernet website for job listings data

Data Security

Your Telegram credentials are stored securely in Chrome's storage and are only used to send notifications through Telegram's official API.

Contact

For any questions or concerns about this privacy policy, please submit your inquiry through our contact form.
